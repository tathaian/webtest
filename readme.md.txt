Trang web tính tiền mua bán đơn giản.

Tính năng:
- Hiển thị toàn bộ danh sách mặt hàng và giá trên trang chính.
- Cột nhập số lượng bên cạnh mỗi mặt hàng.
- Nhập xong nhấn Enter → tự động tính thành tiền của món đó.
- Tổng cộng hiện luôn ở dưới cùng (giá chi tiết).
- Nút Xóa hết để đặt lại số lượng, nút In để in/lưu hóa đơn.

Cách dùng: mở file index.html bằng trình duyệt (hoặc trên điện thoại).
